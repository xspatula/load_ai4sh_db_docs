Utility data provides the controlled vocabularies and reference catalogues that all observation data depends on. It must be loaded before any dataset, sample, or observation data.

All utility loading is driven by the notebook `load_ai4sh_utility_data.ipynb`.

## Required loading sequence

1. Translate general utilities
2. Manage general utilities
3. Translate observation utilities
4. Manage observation utilities
5. Translate observation utilities with inheritance
6. Manage observation utilities with inheritance
